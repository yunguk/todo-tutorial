# 고양이 상식 목록

## 사용자 동작
1. 사용자가 `/cat-facts` 페이지에 들어가면 고양이 상식 목록(각 항목은 미리보기 텍스트)이 보인다.
2. 목록에서 항목을 클릭하면 해당 항목이 펼쳐져 전체 설명(전문)과 글자 수가 보인다.
3. 펼쳐진 항목을 다시 클릭하면 미리보기 상태로 접힌다.
4. Todo 목록 화면(`/`)에서 링크를 눌러 `/cat-facts` 페이지로 이동할 수 있다.

## 데이터 소스
Cat Facts API(`https://catfact.ninja/facts`)에서 서버 사이드로 목록을 가져온다.
