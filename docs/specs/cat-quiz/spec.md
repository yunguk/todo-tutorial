# 고양이 O/X 퀴즈

## 사용자 동작
1. `/cat-quiz` 페이지에 들어가면 한글로 번역된 고양이 상식 문장이 한 문제씩 보인다.
2. 문장이 참(O)인지 거짓(X)인지 고른다.
3. 선택 즉시 정답 여부와 실제 참/거짓이 표시된다.
4. "다음 문제" 버튼으로 다음 문제로 넘어간다.
5. 마지막 문제 후에는 총 정답 수(예: 3/5)를 보여준다.

## 데이터 소스와 결정 사항
- 참(O) 문장의 원문: Cat Facts API(`https://catfact.ninja/facts`)에서 가져온 실제 사실.
- 거짓(X) 문장: Cat Facts API는 거짓 진술을 제공하지 않으므로, 알려진 사실 10개에 대해 정적으로 미리 작성한 "거짓 변형" 문장을 `lib/cat-quiz.ts`에 짝지어 둔다.
- 번역: MyMemory 무료 번역 API(`https://api.mymemory.translated.net/get`, 키 불필요)로 참/거짓 영문 문장을 한국어로 번역한다. 번역 실패 시 영문 원문으로 폴백한다.
- 매 문제마다 참/거짓 여부는 무작위로 선택한다.

## 완료 기준
- [x] `/cat-quiz` 페이지가 Cat Facts API 데이터 중 거짓 변형이 준비된 문장만 골라 퀴즈를 구성한다.
- [x] 각 문장은 MyMemory API로 한국어 번역되어 표시된다(번역 실패 시 영문 폴백).
- [x] 한 번에 한 문제씩 보여주고, O/X 선택 → 정답/오답 표시 → "다음 문제" 흐름이 동작한다.
- [x] 마지막 문제 이후 최종 점수가 표시된다.
- [x] 유닛 테스트로 퀴즈 진행/정답 판정/최종 점수 표시를 검증한다.
